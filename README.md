## Задача

Разработать Python-пакет `streamstats` с консольным интерфейсом, 
предназначенный для потокового чтения логов из файлов форматов JSONL и CSV 
и формирования статистического отчёта без загрузки всего файла в память.

## Возможности

### Чтение и парсинг
- Потоковое чтение файлов построчно (генераторы).
- Поддержка формата JSONL (один JSON-объект на строку).
- Поддержка формата CSV (с заголовком, маппинг по колонкам).
- Валидация событий: проверка полей `timestamp` (ISO 8601), `level` (строгий список), `source` (непустая строка), `message`.
- Объединение нескольких входных файлов в один поток событий.

### Анализ и статистика
- Подсчёт общего количества событий.
- Разбивка событий по уровням (`DEBUG`, `INFO`, `WARNING`, `ERROR`, `CRITICAL`).
- Разбивка событий по источникам.
- Поиск Top-5 источников ошибок (уровни `ERROR` и `CRITICAL`) с детерминированной сортировкой.
- Определение первой и последней временной метки в логах.

### Обработка ошибок
- Строгий режим (по умолчанию): остановка при первой некорректной строке.
- Режим `--skip-invalid`: пропуск битых строк с записью `WARNING` в лог и подсчётом количества пропущенных строк.
- Все пользовательские ошибки выводятся в `stderr`.
- Код возврата при ошибке: `2`.
- Код возврата при успехе: `0`.
